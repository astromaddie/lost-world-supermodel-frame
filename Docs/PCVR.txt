SUPERMODEL VR (PC) - THE LOST WORLD
====================================

What this is
  Desktop Supermodel (the same emulator the Steam Deck runs) with an OpenXR VR mode.
  The PC runs the game at full speed and streams it to the Quest 3. The 3D world is drawn
  in stereo around you; scores and text float on a screen-sized panel in front of you.

Before you start (once)
  1. Put lostwsga.zip in the ROMs folder (or keep it in the folder above this one).
  2. Choose ONE way to connect the Quest and make it the active OpenXR runtime:
     - Virtual Desktop: in the Streamer app on the PC, set "OpenXR Runtime" to VDXR.
     - Meta Quest Link (cable or Air Link): Meta Quest Link app > Settings > General >
       "OpenXR Runtime" > Set Meta Quest Link as active.
     - SteamVR: SteamVR settings > OpenXR > set SteamVR as the OpenXR runtime.

Playing
  1. Connect the headset (Virtual Desktop streaming, Link, or SteamVR running).
  2. Double-click "Play The Lost World VR.bat".
  3. In the headset:
       Trigger (gun hand) ...... fire (the gun is in the hand chosen in the options: right or left)
       Grip (gun hand) ......... reload (the side button of the hand that holds the gun)
       A or Y .................. Start
       B or X .................. Coin
       Left menu button ........ options menu (the game pauses; point and pull the trigger)
       Either stick click ...... re-centre the view (game screen straight ahead)
       Left grip + left stick click ... Test (operator menu) - not needed to play
     The Lost World has no crosshair of its own during play, so a red ring shows where
     the gun hand points (also on the cinema screen). The game's own "X" sight in
     cutscenes is left out, so there is only ever one. VRPointer = 0 in
     Config/Supermodel.ini hides the ring and brings the game's X back.
  4. Esc on the keyboard quits. A normal window on the PC mirrors the game.

Smoothest motion
  The game runs at 60 fps. At 120 Hz every game frame is shown for exactly two headset
  frames, so motion and the crosshair are perfectly even. Supermodel asks for 120 Hz;
  if your streaming app overrides it, set 120 Hz there (Virtual Desktop: Streaming tab >
  Frame rate 120; Quest Link: Meta Quest Link app > Devices > Graphics preferences >
  Refresh rate 120). At 72 or 90 Hz some game frames stay up longer than others.

Virtual Desktop settings for smooth play
  Streaming tab: Frame rate 72 (or 90 if it holds), Synchronous Spacewarp: Disabled.
  With Spacewarp on, Virtual Desktop halves the game to 36 fps whenever a frame is late,
  which looks choppy and makes the crosshair lag.

Options menu (left controller's menu button)
  Point at an option and pull the trigger to choose it. To move the menu, point at it and
  hold the grip (side) button: it follows your aim and turns to face you; let go to drop it.
  Comfort  Vignette - darkens the edges of your view while the game's camera turns fast
                      (Off / Light / Medium / Strong); the best help against motion sickness.
           Cinema mode - the game on a big screen in a dark room: no camera motion around you
                      at all; the screen keeps its size when the game zooms. Small / Medium /
                      Large screen, and 3D depth: Flat / Shallow / Full - like a 3D TV, the
                      game's world sits behind the screen.
           Screen bezel - Off / On: the cinema screen sits in a recessed frame whose sloping
                      inner walls reflect a blurred, mirrored copy of the picture.
           Screen glow - Off / Subtle / Strong: the colours at the edge of the picture light up
                      the dark room around the cinema screen, like a TV's ambient backlight.
  Gun      Gun hand - Right / Left: the hand that holds the gun.
           Gun model in your hand - Off / Game / Custom. Game: the arcade's gun, from
                      Assets/VRGameGun.obj (not included - the game's own gun isn't in its
                      ROM). Custom: your own model (Assets/VRGunModel.obj, see VRGunModel
                      below). Drawn in the hand that holds the gun, from the moment the game
                      starts.
           Gun colour - Blue / Red, like the two cabinet guns (Game model only).
           Recoil vibration - Off / Light / Strong.
           Aim fine-tune - nudge the aim left/right and up/down in 0.1 degree steps, if the
                      pointer ring sits a little off from where your shots land.
  Screen   Score / timer / text - Fixed in the room / Follow head / Auto (head during play).
           2D graphics scaling - Soft / Sharp / Smooth edges (pixel-art upscaling).
           Hide player 2 PRESS START (no effect in The Lost World), static and fades over the
                      whole view.
           Render resolution - 0.5x to 1.5x of the headset's own; applies on the next start.
  Changes are saved to Config/Supermodel.ini straight away.
  Look: the menu uses Assets/VRMenuFont.ttf (Russo One, SIL Open Font License). It can also be
  framed by your own artwork - see Assets/VR-MENU.txt.

Settings (Config/Supermodel.ini, [ Global ])
  VRResolutionScale     1.0 = headset's recommended eye size; raise for sharper image
  VRMaxEyeWidth         cap on pixels per eye (1664). Higher = sharper but more work per
                        frame; raise it (e.g. 2048) only if the headset stays at full rate
  VRHudDistance         metres to the text panel (20 - far, so text and crosshair sit at
                        the same depth as the 3D world and never look doubled)
  VRWorldUnitsPerMeter  stereo scale of the 3D world (1.0)
  VRPositionalTracking  1 = lean in the world, 0 = rotation only
  VRRefreshHz           headset refresh: the highest rate the headset offers, up to this value
                        (1000 = as high as it goes); 0 = leave it alone. With Virtual Desktop the
                        rate is the one chosen in its Streaming settings (72 / 80 / 90 / 120 Hz):
                        raise it there if your PC keeps up. 120 Hz is the smoothest for this
                        game (exactly two headset frames per game frame).
  VRLateLatchMs         longest wait (ms) for a game frame that is about to finish before the
                        headset frame is drawn (5); keeps the game at full speed. 0 = off
  VRPointer             1 = red pointer ring where the gun hand points (on by default: The Lost
                        World has no crosshair during play); also hides the game's cutscene X
  VRHideLetterbox       1 = remove the black cutscene bars, in the headset and on the cinema
                        screen (the score and text in them stay)
  VRMirror              1 = also show the game in the PC window. Switched off automatically
                        for the session if presenting it would slow the headset down
  VRAsyncFrames         1 = the game runs at its own 60 fps, the headset never waits for it
  VRHudLock             2 = score, timer and text follow your head during play and
                        cutscenes and stay fixed in the room on menus; 1 = always follow the
                        head; 0 = always fixed in the room
  VRStaticFill          1 = the game's hit "static" and full-screen fades (e.g. the white veil
                        of the CONTINUE screen) fill your whole view instead of only the
                        original 4:3 screen
  VRBackdropFill        1 = the game's background picture (the sky) continues past the 4:3
                        screen, mirrored at its edges, whenever the 3D world is on screen;
                        0 = only behind the original screen (black around it)
  VRVignette            0-3 comfort vignette (see the options menu)
  VRCinema, VRCinemaSize, VRCinemaDepth, VRCinemaGlow, VRCinemaBezel
                        cinema mode on/off, screen size 0-2, 3D depth 0 flat / 1 shallow / 2 full
  VRGunHand             1 = right, 2 = left (the hand that holds the gun)
  VRGunModel            gun model in your hand: 0 = off, 1 = the game's gun (The Lost World:
                        the arcade gun from Assets/VRGameGun.obj, not included), 2 = your own
                        model from Assets/VRGunModel.obj (falls back to the game's gun if the
                        file is missing). Shown in cinema mode too, in front
                        of the screen and lit by it.
                        Your own model: a Wavefront OBJ in metres, the hand / grip at the origin,
                        barrel pointing along -Z, +Y up; colour from the Kd of its .mtl, plastic
                        gloss from Ks (highlight strength, 0-1) and Ns (sharpness: ~10 matte,
                        ~100 glossy; low values also blur the reflections).
                        The guns are shown from the moment the game starts, not only in play.
  VRGunModelLength      its length in metres (0.75); VRGunModelFlip / VRGunModelUpsideDown = 1
                        turn it round or over if a headset's controller pose needs it
  VRGunColour           the game's gun from Assets/VRGameGun.obj: 0 = blue, 1 = red
  VRRecoil              0 = off, 1 = light, 2 = strong
  VRAimNudgeX/Y         aim fine-tune in degrees
  VRHudFilter           0 = soft, 1 = sharp, 2 = smooth edges
  VRHudLayer            0 = draw score/crosshair into the 3D image (exact alignment);
                        1 = use a separate compositor layer (sharper text, may drift)
  VRGunCalibration      1 = set the wide gun calibration in the game (see below)
  VRAimScaleX/Y, VRAimOffsetX/Y
                        gun correction measured for this game's calibration, so the
                        crosshair lands where you point - leave as is

Start-up
  The game waits until the headset is in use, so you can start it from the PC and then put
  the headset on without missing the opening.
  The first VR start shows the arcade's start-up screens once (warning, copyright); a
  snapshot is saved the moment the attract demo begins, and every later start opens there -
  the beginning, never in the middle of a game. A snapshot that opens in a game (older
  builds could save one at a CONTINUE screen) is deleted automatically and a new one taken.
  To redo it by hand, delete Saves\lostwsga.vrlogo.

Gun calibration
  The VR build sets the game's light gun calibration itself (the values GUN ADJUSTMENT
  stores in the operator menu: centre, left, right, top, bottom), wide enough that the game
  keeps aiming about a screen-width past each edge of its 4:3 screen. No NVRAM file is
  needed. VRGunCalibration = 0 turns this off.

Things the VR build hides
  The game moves its two "X" sight markers (shown in cutscenes) off the screen during play.
  The flat screen never shows them there, but the headset draws beyond the 4:3 frame, so
  they are left out of the eye images whenever they are off the screen.

If VR does not start
  A message box says why and the game runs in a normal window. Supermodel.log in this
  folder has the details (lines starting with "VR:").
